# App audit and appearance cleanup

Use Settings → General → iPhone Storage and Screen Time, where available, as evidence with limited observation windows. Distinguish:
- Recently used.
- Rarely used but necessary for travel, a country, equipment or an account.
- Purchased or deliberately saved for later.
- Unknown usage.
- Explicitly unwanted.

A missing last-used date is not evidence of never-used status. Ask about an apparent date cutoff without assuming a restore occurred. An offload cloud badge indicates the app binary is absent, not that the user wants the app deleted.

Create a concrete candidate list before deletion. Preserve authenticators, password managers, banking tools, regional apps and paid games unless the user chooses to remove them. Follow the current tool's confirmation requirements for permanent local-data deletion. Approval to rearrange icons never authorizes removing apps.

Prefer clearing unwanted downloaded media inside the app over uninstalling and reinstalling; reinstalling can lose settings or require login. If the user wants to curate downloads themselves, leave them to it.

For notification cleanup, turn off only badges when requested, preserving banners, sounds and notification delivery. A high count can be a candidate for hiding, not a reason to delete messages. Distinguish removing a widget from uninstalling its app. Preserve useful photo widgets and labels when the user values them.

Do not promise a free tier or feature from memory. Verify current vendor information for subscription-dependent features. Authentication setup is separate from layout work.

If an email shortcut duplicates its trigger, distinguish iOS Text Replacement from a third-party keyboard suggestion. Test the expansion in a non-sending field. Avoid resetting learned keyboard history without agreement; that affects more than the shortcut.
